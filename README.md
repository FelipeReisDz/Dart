## ⚙️ Executando

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd dart-exercises
```

Execute um exercício:

```bash
dart exercicios/exercicio-01.dart
```
